# KB-005 商品页慢但非数据库

## 典型现象

- 用户反馈商品页面打开很慢，但接口并没有大量数据库超时
- 前端首屏耗时升高，静态资源下载和 hydration 时间明显变长
- 商品详情缓存命中率下降，回源聚合请求增多
- 推荐、画像、活动等下游依赖耗时上升，拖慢商品页整体返回

## 常见信号

- `frontend_first_screen_p95` 持续升高
- `static_bundle_download_p95` 明显高于基线
- `product_detail_cache_hit_ratio` 持续下降
- `recommendation_request_duration_p95` 或 `profile-service` 依赖耗时升高

## 判断重点

1. 先区分是前端首屏阻塞，还是后端聚合慢
2. 如果商品页脚本过大、CDN 缓存未命中或 hydration 变慢，应优先看前端加载链路
3. 如果缓存命中率下降且下游依赖耗时升高，应优先看缓存和依赖，而不是直接归因到数据库
4. 只有出现稳定的连接超时、慢 SQL、锁等待时，才继续把根因收口到数据库

## 建议排查

1. 检查商品页主包体积、静态资源缓存和首屏关键路径
2. 检查商品详情缓存是否击穿或热点失效
3. 检查推荐、画像、活动等下游依赖的耗时和失败率
4. 对比最近发布记录，确认是否引入了新的前端阻塞点
