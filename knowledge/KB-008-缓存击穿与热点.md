# KB-008 缓存击穿与热点

## 典型现象

- 热门商品、首页推荐或活动页在短时间内突然变慢
- 缓存命中率下降，热点 key 频繁失效或集中回源
- 单个接口的数据库压力不一定高，但下游聚合请求会突然变多
- 商品页慢、推荐慢、详情页抖动经常和缓存热点同时出现

## 常见信号

- `cache_hit_ratio` 下降
- `hot_key_qps` 或热点 key 访问量异常升高
- 回源请求数突然抬升
- 预热任务失败或缓存过期时间集中到期

## 判断重点

1. 先区分是稳定性能退化，还是热点流量导致的瞬时回源
2. 缓存未命中和热点击穿会把商品页、推荐链路一起拖慢
3. 如果缓存命中率和热点访问量异常同步出现，应优先看缓存层
4. 不要因为最终回源请求落到后端，就直接把问题判断成数据库故障

## 建议排查

1. 检查热点 key、缓存命中率和回源请求趋势
2. 检查是否存在大批缓存同时过期
3. 检查预热、互斥锁和空值保护是否生效
4. 对热点接口单独做限流和预热验证
