# KB-006 支付网关抖动

## 典型现象

- 结账失败了
- 支付一直转圈
- `payment-service` 返回 `504`、`Gateway timeout` 或回执迟迟未到
- 重试次数耗尽后，前端仍在等待支付结果

## 常见信号

- `payment_gateway_upstream_latency_p95` 持续升高
- `payment_gateway_upstream_error_rate` 明显高于基线
- `payment_gateway_retry_exhausted_total` 持续增加
- `payment_result_pending_requests` 堆积

## 判断重点

1. 先确认异常是否集中在 `payment-gateway` 或外部支付回执链路
2. 如果网关超时、重试耗尽、熔断半开同时出现，应优先判断为支付网关抖动
3. 支付转圈不等于数据库异常，很多时候是前端轮询一直等不到网关回执
4. 如果支付链路失败点稳定落在网关，结论不要被无关的容量信号带偏

## 建议排查

1. 检查支付网关状态页、上游 SLA 和最近错误码分布
2. 检查 `payment-service` 的超时、重试和熔断配置
3. 统计 `504`、回执超时和轮询等待时间的时间窗口
4. 如果有备用通道，验证切换后是否恢复
