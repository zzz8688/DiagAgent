# KB-003 订单链路内部依赖错误

## 故障现象
- 日志中出现 `internal dependency error`、`Failed to call`、`dependency request failed`
- `order-service` 调用 `product-service`、`payment-service` 或 `promotion-service` 时返回 5xx 或超时
- 失败点落在内部微服务，不是外部支付网关或前端登录态

## 涉及服务
order-service -> product-service/payment-service/promotion-service

## 根因分析
下游服务出现故障或响应超时

## 影响范围
上游服务无法完成请求，导致级联失败

## 处理步骤
1. 从日志中提取 Trace ID
2. 通过链路追踪定位具体故障服务
3. 检查故障服务的日志和指标
4. 确认故障服务恢复后重新尝试

## 不适用场景
1. 支付网关 `504`、重试耗尽或回执超时
2. 商品页首屏阻塞、缓存击穿或推荐依赖变慢
3. 鉴权服务会话刷新失败、token 校验异常或登录重定向循环

## 预防措施
1. 实现服务熔断机制
2. 配置合理的超时时间
3. 实施降级策略
