# KB-009 前端会话与鉴权异常

## 典型现象

- 页面一直转圈、重复跳登录或偶发提示无权限
- 用户明明已登录，但接口返回 `401`、`403` 或 token 刷新失败
- 部分请求成功、部分请求失败，表现得像系统异常但不稳定
- 首屏加载阶段就卡住，且与会话刷新或鉴权校验有关

## 常见信号

- `token_validation_latency_p99` 升高
- `session_refresh_failure_ratio` 抬升
- 浏览器端出现重复刷新 token、会话失效或重定向循环
- `auth-service` 实例异常或健康分下降

## 判断重点

1. 如果异常集中在登录态、token 刷新和权限校验，优先看会话与鉴权链路
2. 前端一直转圈不一定是后端慢，也可能是鉴权请求循环等待
3. 巡检型问题如果同时出现实例异常和鉴权延迟，要先给出健康结论
4. 不要把会话问题误判成数据库或商品服务故障

## 建议排查

1. 检查 token 刷新、会话续期和重定向逻辑
2. 检查 `auth-service` 的实例健康、错误率和延迟
3. 对比浏览器日志、网关日志和鉴权服务日志
4. 核对最近是否有登录态、Cookie、Header 或跨域配置变更
