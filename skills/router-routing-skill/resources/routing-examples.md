# 路由表达示例

本文件同时提供正式路由示例和表达方式，供主智能体在边界模糊时参考。

## app

- 可表述为“优先交给应用专科智能体进一步诊断”
- 可表述为“先按应用层问题处理，再补日志与指标证据”
- 典型问题：`服务挂了`、`接口报错`、`Token过期`、`认证失败`

## db

- 可表述为“优先交给数据库专科智能体进一步诊断”
- 可表述为“先确认数据库连接、慢查询或连接池指标”
- 典型问题：`商品加载很慢`、`数据库连接超时`、`订单加载慢`

## network

- 可表述为“优先交给网络专科智能体进一步诊断”
- 可表述为“先确认网络可达性、DNS、网关或连接错误”
- 典型问题：`支付超时`、`支付失败`、`网络延迟`

## all

- 可表述为“当前无法单点归类，需要主智能体并行触发多个专科智能体”
- 可表述为“当前信息不足，先走全局排查路径”
- 典型问题：`系统健康检查`、`系统很慢`、`多个服务同时异常`
